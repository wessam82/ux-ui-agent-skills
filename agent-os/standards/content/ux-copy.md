# UX Copy

Plain language. Active voice. Start with the verb. Never blame the user.

| Do | Don't |
|----|-------|
| Save changes | Click here to save your changes |
| Email is required | The email field cannot be empty |
| Password needs 8+ characters. Add a number or symbol. | Error: Invalid input |
| No projects yet. Create your first project. | No data |

- Errors: what happened → how to fix it
- Empty states: the value → the first action
- Use familiar labels and icons (magnifying glass = search)
